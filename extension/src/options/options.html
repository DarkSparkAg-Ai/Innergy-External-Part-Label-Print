Prints one label without ticking anything. The menu only exists while it is open, so it is more exposed to Innergy changing its markup than the toolbar button — turn this off if it misbehaves and the toolbar button carries on working.

Pages

One per line. Paste the address straight from the address bar — a full URL, or just the #/… part, both work. Saving rewrites each line to the short form it matched on, so you can see what it understood. * is a wildcard. Add more parts grids here — no code change needed.

Diagnostics

Open the Innergy parts grid, tick a few rows, then click below. This reports exactly what the extension can see on that page — send it to whoever maintains this extension when the button doesn't appear or nothing prints.

Advanced

Leave these blank unless an Innergy update broke the automatic detection. Use the diagnostics above to see what it found.
